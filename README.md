# Lsy的Excel-Tool

一个在 Windows 上运行的轻量级 Excel 工具（单个 exe，无需安装 Python / Excel），提供四大功能：

1. **批量重命名**：把一个或多个 Excel 文件，按"单元格组合"规则复制重命名到新文件夹（原文件保留不动）
2. **模板填充**：把多个 Excel 文件的数据，按映射关系填入同一个模板的对应单元格，批量生成"模板名_源文件名"的新文件
3. **行/列删除**：按条件批量删除整行/整列
4. **端口拆分**：按"集客系统端口号"等列的不同值拆成多个子表，按流量列排序、标红指定行并汇总

## 使用方法

### 功能一：批量重命名

1. 打开 **批量重命名** 标签页
2. **选择文件…**（可多选）或 **选择文件夹…**（可选"包含子文件夹"）
3. 在 **重命名规则** 中添加规则元素，可自由排列组合：
   - **单元格**：如 `A1`、`B2`，读取该文件第一个工作表中该单元格的内容
   - **文字**：自己打字输入任意字符，原样保留
   - **原文件名**：该文件的原始文件名（不含扩展名）
4. 用上移/下移调整元素顺序；设置分隔符（如 `-`、`_`，留空为无）
5. 点击 **预览**，确认每个文件将生成的新文件名
6. 选择 **输出文件夹**，点击 **开始重命名**

> 说明：新文件名 = 规则元素按顺序拼接。**分隔符只插在相邻的"单元格/原文件名"之间，文字原样保留**（如规则 `文字"客户_"` + `A1` + `原文件名` + `文字"_已审"`，分隔符 `-` → `客户_张三-数据1_已审`）。空单元格自动跳过；若全部为空则回退为原文件名。自动处理非法字符（`\ / : * ? " < > |` 替换为 `_`）、超长文件名截断、重名自动加 `(1)` `(2)`。

### 功能二：模板填充

1. 打开 **模板填充** 标签页
2. 选择源文件（数据来源）+ 一个模板文件
3. 在 **映射表** 中添加映射（均指第一个工作表），支持三种方式：

   **① 单元格 → 单元格**：把源文件的某个单元格内容填入模板的某个单元格，如 源 `A1` → 模板 `B2`。

   **② 整列 → 整列**：把源文件某一列的整段数据填入模板某一列：
   - 设置 **源列** 和它的 **起始行**（源列从该行向下，读到第一个空单元格为止，即为要填入的数据）
   - 设置 **模板列** 和它的 **起始行**（数据从该行开始向下填入）
   - 若模板目标位置**已有内容**，**不会覆盖**，而是**插入空白行**把下方内容整体下移，扩展出空间容纳源列数据（新插入的行继承表格边框样式）
   - 例：源 `B列 从第2行` → 模板 `A列 从第6行`，源列有 5 条数据，模板 A 列第 6、7 行原有内容会被推到第 11、12 行，新数据填在第 6–10 行

   **③ 列求和 → 单元格**：把源文件某一列自指定行起（到空单元格为止）的所有数值求和，结果填入模板某个单元格：
   - 设置 **源列** 和它的 **起始行**
   - 设置 **模板单元格**（求和结果填入处，支持合并单元格，自动定位到合并区左上角）
   - 单元格中的**数值型字符串**（如 `" 100 "`、`"1,500.5"`，含前后空格、千分位逗号）会自动准确转成数字参与求和；非数值文本自动跳过
   - 模板单元格的数字格式（如 `#,##0.00`）会自动应用到求和结果

4. 点击 **预览**，确认输出文件名（模板名 + 源文件名）
5. 选择 **输出文件夹**，点击 **开始填充**

> 说明：模板的样式（字体、边框、合并单元格、数字格式等）会完整保留；数值/日期按原类型写入，模板单元格的数字格式会自动生效。整列填充的插入行会继承下方数据行的边框样式；若模板数据区包含合并单元格，插入行不会自动调整合并范围（建议整列填充的模板数据区避免使用合并单元格）。

### 功能三：批量行/列删除

对多个 Excel 文件，按您指定的条件**删除行或删除列**，原文件保留、结果输出到新文件夹：

1. 打开 **行/列删除** 标签页
2. 选择文件 → 设置删除对象（**删除行 / 删除列**）
3. **添加查找条件（可多条）**：输入内容 + 选择匹配方式（**包含 / 等于**），点"添加"；可添加多条，任一条件匹配即删除。可选"区分大小写"
4. 点击 **预览** 查看每个文件将删除多少行/列
5. 选择输出文件夹，点击 **开始删除**

> 说明：删除范围为**整行/整列中任意单元格**满足任意一条条件即删除。例如同时添加"小结(等于)"和"计算(等于)"两条，则等于"小结"或等于"计算"的行都会被删除。支持 `.xlsx/.xlsm/.xls`；合并单元格会随删除自动调整或移除。
>
> **保存规则**：可把删除对象、多条查找条件和区分大小写保存为一条规则，下次在下拉框选中 → 载入即可，无需重复设置。

### 功能四：端口拆分

把一个表格按"端口号"列的不同值拆成多个子表，每个子表按流量列排序，并标红/汇总指定行：

1. 打开 **端口拆分** 标签页
2. **选择文件…**（`.xlsx` / `.xlsm`，读取第一个工作表）
3. 设置三个列名（默认已填好）：
   - **端口号列名**：默认 `集客系统端口号`
   - **流入速度列名**：默认 `流入速度`
   - **流出速度列名**：默认 `流出速度`
4. 设置 **标红行号**：默认 `448`，**含表头**（第 1 行是表头，所以第 448 行是第 447 条数据）
5. 点击 **预览**，确认每个端口号拆出的行数、流入/流出总和、实际用于排序的列
6. 选择输出文件夹，点击 **开始拆分**

> 处理规则：
> - 按端口号列的**不同内容**分组，每个端口号生成一个工作表；**表头（第 1 行）与原表完全一致**
> - 分别计算**每个子表**的"流入速度"总和与"流出速度"总和，**哪个总和大就按哪一列降序排列**（两者相等时按流入速度）；数值型字符串（含千分位逗号）按数字比较，非数值/空值排在最后
> - 排序后，每个子表的**第 448 行整行字体标红**（行号可改）；若该子表数据不足 447 行，则不标红
> - 所有子表的标红行会汇总到最后一个工作表 **"448行汇总"** 中，汇总行同样标红
> - 输出为一个 `.xlsx` 文件，文件名 = `原文件名_按端口拆分.xlsx`；原文件保留不动
> - 保留单元格字体/填充/边框/数字格式、列宽和冻结窗格；**合并单元格不保留**（按普通数据行处理）
> - 该功能暂不支持旧版 `.xls`，请先在 Excel 中另存为 `.xlsx`

### 保存与调用规则（避免重复设置）

在**重命名规则**和**映射表**区域各有一组按钮，只保存规则本身（不保存文件列表和输出文件夹）：

- **保存当前规则… / 保存当前映射…**：把当前的重命名规则（单元格 + 分隔符）或映射表保存为一条记录，可输入名称（留空用时间命名），已存在的名称可覆盖
- **已保存规则 / 已保存映射**（下拉框）：列出所有保存过的记录
- **载入**：把选中的记录恢复到规则区/映射表，直接使用或继续修改
- **删除**：删除选中的记录

可保存**多套规则**，随时调用。配置文件 `Lsy的Excel-Tool_profiles.json` 与软件放在同一目录，**拷贝 exe 时一起拷贝即可带走规则**。

## 格式支持

支持 `.xlsx` / `.xlsm` / 旧版 `.xls` 三种格式的读取与处理：
- **批量重命名**：三种格式均可作为源文件（读取单元格 → 复制重命名，`.xls` 原样保留）
- **模板填充**：源文件三种格式均可；模板为 `.xlsx/.xlsm` 用新格式处理，模板为 `.xls` 时采用整表重建（xlrd 读 + xlwt 写），样式/边框/合并单元格尽量保留，整列填充的"插入空白行"同样支持
- **行/列删除**：三种格式均可
- **端口拆分**：支持 `.xlsx / .xlsm` 输入，统一输出 `.xlsx`

## 已知限制

- 单元格一律读取文件的**第一个工作表**
- 公式单元格只读取 Excel 已缓存的计算结果；若文件由程序生成且从未在 Excel 打开过，公式结果可能为空
- 模板填充保存时，模板中的**图表和图片会丢失**（普通合同/标签类模板不受影响）
- `.xls` 模板重建时，复杂样式（如部分特殊填充/字体）可能无法 100% 还原；图表/图片不支持
- **端口拆分**暂不支持旧版 `.xls`；输出不保留合并单元格、图表、图片、条件格式、数据验证等，但会保留字体/填充/边框/数字格式/列宽/冻结窗格
- 端口拆分按单元格**文本内容**分组（忽略首尾空格），大小写和全半角不同会视为不同端口号
- 源文件被 Excel 打开时可能无法读取/写入，软件会跳过该文件并给出提示，不会中断整个批次

## 开发与打包

环境要求：Windows + Python 3.10+。

```bash
# 运行依赖
python -m pip install -r requirements.txt

# 开发调试（从终端运行，可看到报错）
python app.py

# 生成测试样例
python test_make_samples.py

# 一键打包（生成 dist\Lsy的Excel-Tool.exe）
build.bat
```

把 `dist\Lsy的Excel-Tool.exe` 拷贝到其他 Windows 10/11 电脑上双击即可运行。
首次运行可能弹出 SmartScreen"已保护你的电脑"提示（软件未签名），点 **更多信息 → 仍要运行** 即可。
